# Backend

This directory contains the FastAPI backend for Landslide-WebGIS.

## Responsibilities

- Connect to PostgreSQL/PostGIS.
- Provide APIs for geographic and application data.
- Retrieve and process rainfall information.
- Execute rule-based warning logic.
- Provide susceptibility map metadata and layer references.
- Support the React WebGIS frontend.

## Technology

- Python
- FastAPI
- PostgreSQL
- PostGIS
