# Project Overview

## 1. Project Information

| Item | Description |
|---|---|
| Project Name | Landslide-WebGIS |
| Project Type | WebGIS |
| Domain | GIS and Natural Disaster Management |
| Study Area | Lai Chau, Dien Bien, Son La, and Yen Bai |
| Analysis Method | Rule-based scoring and weighted overlay |

## 2. Background

Mountainous areas in Northern Vietnam are vulnerable to landslides due to terrain characteristics, geological conditions, land cover, soil properties, and rainfall.

Geographic information systems can support the analysis and visualization of areas with different levels of landslide susceptibility.

However, a static susceptibility map does not reflect changing rainfall conditions. Therefore, this project combines GIS-based susceptibility mapping with rainfall information to support dynamic, rule-based warnings.

## 3. Problem Statement

The project addresses the following problems:

- Geographic and environmental data are collected from different sources and formats.
- Multiple environmental factors need to be standardized and analyzed consistently.
- Susceptibility information needs to be presented through an accessible web map.
- Rainfall information needs to be integrated with spatial susceptibility information.
- Warning information needs to be managed and displayed in a centralized system.

## 4. Project Objectives

1. Prepare geographic and environmental datasets for the study area.
2. Analyze landslide-related factors using QGIS.
3. Construct a landslide susceptibility map using a documented weighted overlay methodology.
4. Develop a spatial database using PostgreSQL and PostGIS.
5. Integrate rainfall data from an external weather API.
6. Develop a rule-based warning engine.
7. Build an interactive WebGIS application.
8. Provide map visualization and warning information to users.

## 5. Study Area

The initial study area consists of four provinces in Northern Vietnam:

- Lai Chau
- Dien Bien
- Son La
- Yen Bai

The study area is represented using administrative boundary data.

The main GIS analysis uses:

- Coordinate Reference System: EPSG:32648
- Target Raster Resolution: 250 meters

## 6. Project Scope

### 6.1. Included

- GIS data collection and preprocessing.
- Terrain, geology, land cover, soil, road, and river factor analysis.
- Rule-based factor scoring.
- Weighted overlay susceptibility mapping.
- Spatial database development.
- Rainfall data integration.
- Rule-based warning generation.
- Interactive WebGIS visualization.

### 6.2. Excluded

- Machine learning-based landslide prediction.
- Deep learning-based image classification.
- Automatic real-time landslide detection.
- Guaranteed prediction of the exact time and location of landslides.

## 7. Main System Functions

| Function | Description |
|---|---|
| Susceptibility Map | Display landslide susceptibility zones |
| GIS Layer Management | Display and control geographic layers |
| Rainfall Information | Display rainfall observations or forecasts |
| Warning Information | Display warnings generated by predefined rules |
| Area Information | Display information about selected administrative areas |
| Historical Events | Display available historical landslide records |

### Administrators
- Manage datasets and map versions.
- Monitor rainfall records and warning information.
- Manage system configuration.

## 9. Expected Deliverables

- Processed GIS datasets.
- Landslide susceptibility map.
- PostgreSQL/PostGIS database.
- FastAPI backend.
- React + Leaflet WebGIS frontend.
- Rainfall integration and warning module.
- Technical documentation.

## 10. Limitations

The susceptibility map represents relative spatial susceptibility based on selected factors and documented scoring criteria.

The warning system is rule-based and depends on rainfall data availability, data quality, spatial coverage, and the validity of configured thresholds.

The system is intended to support geographic awareness and information visualization, not replace official disaster-warning authorities.
