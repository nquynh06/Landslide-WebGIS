# Project Documentation

This directory contains the technical documentation of the Landslide-WebGIS project.

## Documentation Index

| File | Description |
|---|---|
| `project_overview.md` | Project background, objectives, scope, and study area |
| `system_architecture.md` | Overall system architecture and component interactions |
| `data_dictionary.md` | Definitions of datasets, fields, and attributes |
| `data_sources.md` | Dataset sources, licenses, and collection methods |
| `gis_methodology.md` | GIS preprocessing, factor analysis, and weighted overlay methodology |
| `database_design.md` | Database schema, entities, relationships, and spatial data management |
| `api_specification.md` | Backend API endpoints, request and response structures |
| `rubric_and_weights.md` | Scoring criteria, classification thresholds, and factor weights |

## Documentation Guidelines

- Keep technical decisions documented.
- Record the source of datasets and analytical criteria.
- Update documents whenever the implementation changes.
- Ensure that GIS, database, backend, and frontend documentation use consistent terminology.
